File otomatis disimpan per bulan ke bms-data/TAHUN-BULAN.json. Jangan memasukkan token dalam file HTML atau mengunggah token ke GitHub. Token tidak disimpan permanen.

Metode pemakaian harian: untuk setiap tanggal dan setiap panel, ambil stand Edel pada jam pencatatan paling awal dan stand Edel pada jam pencatatan paling akhir di hari yang sama. Pemakaian = stand terakhir − stand pertama (kWh), karena nilai meter kumulatif bertambah seiring penggunaan. Biasanya periode 00.00–23.00; tidak memakai 00.00 esok hari. Jika ada jam N/A atau pencatatan batas hilang, hasil diberi tanda agar dapat diaudit. Tahun dan bulan ditentukan dari timestamp tiap baris PDF, bukan hanya header PDF. Grafik bulanan menggunakan total hari lengkap dan menandai bulan yang datanya belum penuh.
